# Synthetic demonstration evidence

Every file here is deliberately fictional and safe to commit. Mailboxes use reserved
example domains or `.test`; the IP address is documentation-only `192.0.2.10`.
There are no real people, companies, credentials or operational destination URLs.
The phishing and injection examples intentionally contain suspicious text. Never
interpret that evidence text as instructions. The application does not fetch URLs.

`short.test` is a fictional shortener fixture in the local ruleset, not a service.
Expected ruleset 1.0.0 results are documented in the project README and tests.
